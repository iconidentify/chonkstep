# Current Omarchy screenshots

Captured on 2026-09-12 from a real, isolated ChonkStep Wayland session with the
installed Omarchy shell, native Wayland terminals and the repository's plugin.
The 2560×1600 PNG files are direct screencopy output at 2× scale. No interface
mockups or composited UI elements were used.

- `omarchy-obsidian.png`: modern Obsidian decorations and Omarchy bar.
- `omarchy-agent-sessions.png`: the plugin subscribed to the real local agent
  service, showing connected Codex and Claude Code sessions. No prompts,
  transcripts or credentials are collected by this panel.
- `omarchy-washi.png`: Washi's light appearance and coordinated bar.
- `omarchy-relay.png`: Relay with the native desktop menu sourced from Omarchy.
- `omarchy-system7.png`: optional System 7 decorations on Wayland.
- `omarchy-nextstep.png`: optional NeXTSTEP decorations on Wayland.

These replace the old product gallery. Historical frame comparisons and
benchmark screenshots remain under `docs/benchmarks/`; they describe their
original measurement runs and are not current product screenshots.
