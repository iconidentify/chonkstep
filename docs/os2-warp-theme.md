# OS/2 Warp 4

Choose **OS/2 Warp 4** in the theme menu, with decoration style **auto**.
The theme uses the original 1996 Workplace Shell appearance: recessed purple
captions, gray beveled frames, bitmap text, isometric menu folders, and IBM's
textured blue wave-logo wallpaper.

```toml
theme = "os2-warp-4"
decoration_style = "auto"
```

The title icon opens the window menu. The three right controls close, minimize,
and maximize/restore. Desktop and window menus, cascades, the switcher, minimized
previews, Overview, workspace labels and close buttons receive custom styling.
Application light/dark appearance preserves the original desktop colors.

Use `decoration_style = "os2warp"` to combine the frame and shell recipe with
another theme. Choose **OS/2 Warp 4** in the wallpaper menu to use just its ground.

Historical frame, title, menu glyph and folder pixels are checked against real
OS/2 captures. Integer scales preserve those pixels; fractional scales, Unicode
fallback, live previews and modern workspace surfaces are adaptations. External
applications and Omarchy retain their own widget/bar layouts.
