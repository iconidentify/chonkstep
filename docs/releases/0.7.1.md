# ChonkStep 0.7.1

Display restore, an opt-in Apple M3 GPU session, and output and seat fixes
since 0.7.0. Published through the `preview-v0.7.1` prerelease channel.

## Highlights

- **Displays:** Desktop mode puts a freeform window back on its original
  monitor, at its old position and size, when a display that was unplugged
  comes back. A move, resize, maximize, or fullscreen while it is gone is
  kept. Spaces mode already restored these windows. Disconnecting the last
  monitor no longer shrinks the windows that remain.
- **Modes and lid:** a connector that refuses its chosen timing falls back
  through the other advertised modes, so a 4K display on a bandwidth-limited
  dock can come up at a refresh rate the link can carry. Closing the lid
  stays awake while the session is driving an external output, including an
  Apple Silicon USB-C or Thunderbolt connector named `USB-*`.
- **Seat:** DRM devices opened only to list connectors are handed back to
  the seat, including a secondary GPU whose notifier fails to adopt.
- **Pointer:** clicking the window the pointer is already over does not
  inject a motion at the press position, so a drag's first move is the
  first real movement.
- **Apple M3, opt-in:** `scripts/install-m3gpu-session.sh` installs an
  experimental GPU session. When the native display card is present, Mesa's
  kmsro path renders with zink straight into its scanout buffers. Xwayland
  inherits that graphics stack. External Thunderbolt displays can be adopted
  on this session, and fullscreen scanout keeps the client's buffer layout.
  `CHONKSTEP_RENDER_DEVICE` targets a display-only device such as simpledrm,
  and `CHONKSTEP_DMABUF_REQUIRE_MESA` offers linux-dmabuf only to one Mesa
  build. LINEAR dma-bufs import on drivers that refuse implicit modifiers.
- **Defaults and themes:** the spawned terminal uses a 12 px face, matching
  Omarchy's 9 pt Foot default at 96 DPI. Super+Space runs
  `omarchy-menu toggle`. BeOS R5 and OS/2 Warp 4 themes are included.

## Validation and limits

The parent revision on main,
[`9d2c25c`](https://github.com/iconidentify/chonkstep/commit/9d2c25c1b16179d40be65522c2c03d906238ee44),
passed the full CI suites, including the nested desktop and Spaces
reconnect tests and the pointer-drag coordinate tests. This release commit
changes version, changelog, and notes only. The release workflow validates
that exact revision and checks native package identity and GitHub build
provenance before publishing.

The M3 GPU session is experimental. Nested CI does not qualify physical
DCP scanout, Thunderbolt display replug, lid inhibition, or a dock link
that refuses its preferred mode. Those need the machine they describe.
Mirroring and a second DRM device remain unsupported.

The Debian/LCOS package contains the X11 session. Wayland protocols, the
M3 GPU session, and display restore of a Wayland desktop require the native
Arch Wayland package. Install the new binaries, then log out and back in;
a configuration reload does not replace the running compositor.

## Installing on Arch or Omarchy

Download the package for your architecture and verify its checksum:

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_arch="$(uname -m)"
chonkstep_pkg="chonkstep-0.7.1-1-$chonkstep_arch.pkg.tar.zst"
curl -fL -o "$chonkstep_dir/$chonkstep_pkg" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.1/$chonkstep_pkg"
curl -fL -o "$chonkstep_dir/SHA256SUMS" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.1/SHA256SUMS"
(cd "$chonkstep_dir" && sha256sum --ignore-missing --check SHA256SUMS)
sudo pacman -U "$chonkstep_dir/$chonkstep_pkg"
omarchy install desktop-chonkstep
```

Both `x86_64` and `aarch64` packages have matching `chonkstep-debug-0.7.1-1-`
packages for crash reports. Verify native package provenance with:

```sh
gh attestation verify "$chonkstep_dir/$chonkstep_pkg" \
  --repo iconidentify/chonkstep \
  --signer-workflow iconidentify/chonkstep/.github/workflows/package.yml
```

## Installing on LCOS

Download the amd64 X11 package and its checksum from the
[0.7.1 release](https://github.com/iconidentify/chonkstep/releases/tag/preview-v0.7.1):

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_deb="chonkstep_0.7.1-1_amd64.deb"
curl -fL -o "$chonkstep_dir/$chonkstep_deb" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.1/$chonkstep_deb"
curl -fL -o "$chonkstep_dir/$chonkstep_deb.sha256" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.1/$chonkstep_deb.sha256"
(cd "$chonkstep_dir" && sha256sum --check "$chonkstep_deb.sha256")
sudo apt install "$chonkstep_dir/$chonkstep_deb"
```

Select **chonkstep** in LightDM for the next login. Verify package provenance
with:

```sh
gh attestation verify "$chonkstep_dir/$chonkstep_deb" \
  --repo iconidentify/chonkstep \
  --signer-workflow iconidentify/chonkstep/.github/workflows/lcos-package.yml
```
