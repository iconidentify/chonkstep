# ChonkStep 0.3.2 preview

ChonkStep 0.3.2 brings macOS-style desktop gestures and a lighter live Overview
to the native Wayland session.

## Highlights

- Swipe left/right with three or four fingers to change workspaces, up to open
  Overview, and down to dismiss it. Actions commit on finger lift. Gesture
  enablement, finger count and travel threshold are configurable.
- Overview presents proportionally scaled live windows over your wallpaper,
  with desktop thumbnails across the top. It preserves portrait/landscape
  shapes and relative window sizes without resizing applications.
- Window titlebars stop below a top bar's reserved area, including Omarchy's
  bar, during placement, dragging, resizing and session restoration. Bars that
  appear late also move titlebars below them. Fullscreen covers the full output.
- New applications appear in an already-open Overview, and shading a Wayland
  window no longer leaves stale borders behind.

## Performance and validation

The recognizer uses at most 40 bytes per seat, has no helper thread or polling
timer, and allocates nothing during swipe updates. Overview reuses existing GPU
textures and cached captions, avoiding screenshot readbacks and an output-sized
shell pixel buffer. Closing Overview releases its scene and labels.

Three nested software-rendered sessions per binary with six windows measured
median first-open PSS growth of **2,104 KiB versus 19,888 KiB** before, about 89%
less. Cumulative input-dispatch time across 12 open/select/close cycles fell
from **534,523 to 33,873 microseconds**, about 94%. Overall presentation latency
did not improve proportionally. These are fixture measurements, not hardware
frame-time guarantees.

Feature qualification passed strict Clippy, documentation, workspace and
Wayland unit checks, all 26 Python harness tests, and 11 nested optimized
compositor cases covering Overview, gestures, fullscreen and buffer-age capture.
The tests check live pixels, exposed wallpaper, window geometry and bar
boundaries at 1x/2x scale; an allocation test covers 100,000 recognition updates
and snapping queries. The installed Apple DRM session was also visually checked.

Gestures currently commit on finger lift; transitions do not follow the fingers.
The top desktop thumbnails show wallpaper. X11 retains the rasterized Overview
fallback and does not receive the native libinput swipe stream. Physical
trackpad latency has not been measured.

## Install on Arch or Omarchy

Choose the native `x86_64` or `aarch64` package:

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_arch="$(uname -m)"
chonkstep_pkg="chonkstep-0.3.2-1-$chonkstep_arch.pkg.tar.zst"
curl -fL -o "$chonkstep_dir/$chonkstep_pkg" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.3.2/$chonkstep_pkg"
curl -fL -o "$chonkstep_dir/SHA256SUMS" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.3.2/SHA256SUMS"
(cd "$chonkstep_dir" && sha256sum --ignore-missing --check SHA256SUMS)
sudo pacman -U "$chonkstep_dir/$chonkstep_pkg"
omarchy install desktop-chonkstep
```

The release workflow builds and verifies packages natively for each architecture
and publishes matching debug symbols, `SHA256SUMS`, and GitHub build provenance.
