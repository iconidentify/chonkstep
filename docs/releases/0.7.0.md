# ChonkStep 0.7.0

The NeXTSTEP dock returns as **Chonk Dock**, an optional application with its
own process and native X11 and Wayland backends. The dock, its instruments and
its samplers are independent of both compositor binaries. Omarchy starts none
of them. This minor release uses the existing `preview-v0.7.0` prerelease channel.

## The standalone dock

- Original instrument artwork, clock, traffic graph, CPU/memory, audio, network,
  Bluetooth and power tiles, including the audio, network and Bluetooth panels.
- Application pins, running indicators, launch-or-focus, tile reordering,
  workspace Clip and minimized-window restore tiles.
- Dockapp hosting with authenticated transport, bounded frame queues, liveness
  checks and crash supervision. The Rust, Python and Go SDKs, clock, Shelf,
  appearance switch and protocol tests return under the `dock/` subproject.
- `chonk-get` installs dockapps from source directories or Git URLs. Failed
  upgrades preserve the previous installation; bundled Rust workspace examples
  build in their workspace before their binaries are copied into place.
- Native Wayland layer-shell and X11 EWMH windows, live scale/DPI changes and
  output selection. X11 also gains standard external-panel strut handling in
  the window manager, so a maximized window follows the dock's reservation and
  reclaims the column when the dock exits.

The Arch and Debian/LCOS packages install the optional application, helpers and
launcher. They do not enable an autostart entry or service. Run:

```sh
chonk-dock
chonk-dock --status
chonk-dock --stop
chonk-dock --toggle
```

The backend is selected from the session; `--x11` or `--wayland` overrides it.
Use the same override for subsequent control commands. `--output NAME` chooses
an output, and `--scale 1.25` enlarges the UI. Quit, stop and toggle-off end the
process, shut down hosted dockapps and release its surfaces and reserved space.
See the [dock guide](../../dock/README.md) for configuration and SDK examples.

## Validation and limits

The release gate runs workspace tests, strict Clippy and Rustdoc, dependency
auditing, SDK tests, installation checks and native package verification.
The new isolated X11 test covers launcher execution/focus, minimized-window
restore, workspace Clip, repeated popup dismissal, live DPI changes, dockapp
shutdown, restart and workarea release. The four native Wayland tests cover the
absent-dock default, popup lifecycle, scaling, dockapp shutdown and reservation
release. Package verification checks the dock and its helpers alongside the
session binaries, including matching debug symbols and build provenance.

This remains a preview release. One dock process selects one output. Minimized
tiles show application labels rather than window snapshots. Dockapps start
fresh after a dock restart; the standalone application does not use the old
host's hot-handoff path. X11 reserves a column only at the outer right edge of
the X screen, because an internal monitor edge cannot be represented by an
EWMH strut without reserving the neighboring output. On Wayland the workspace
Clip needs ChonkStep's control socket; on X11 it can also use standard EWMH
workspace selection. Protocol support and scale handling were tested in nested
Wayland sessions and Xvfb, not every physical display configuration.

The Debian/LCOS package still supplies the X11 window-manager session. The dock
itself supports both protocols, without adding a compositor or seat service.
Install the new binaries and log out and back in to update the running window
manager; changing configuration alone does not replace it.

## Installing on Arch or Omarchy

Download the package for your architecture and verify its checksum:

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_arch="$(uname -m)"
chonkstep_pkg="chonkstep-0.7.0-1-$chonkstep_arch.pkg.tar.zst"
curl -fL -o "$chonkstep_dir/$chonkstep_pkg" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.0/$chonkstep_pkg"
curl -fL -o "$chonkstep_dir/SHA256SUMS" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.0/SHA256SUMS"
(cd "$chonkstep_dir" && sha256sum --ignore-missing --check SHA256SUMS)
sudo pacman -U "$chonkstep_dir/$chonkstep_pkg"
omarchy install desktop-chonkstep
```

Both `x86_64` and `aarch64` packages have matching `chonkstep-debug-0.7.0-1-`
packages for crash reports. Verify native package provenance with:

```sh
gh attestation verify "$chonkstep_dir/$chonkstep_pkg" \
  --repo iconidentify/chonkstep \
  --signer-workflow iconidentify/chonkstep/.github/workflows/package.yml
```

## Installing on LCOS

Download the amd64 X11 package and its checksum from the
[0.7.0 release](https://github.com/iconidentify/chonkstep/releases/tag/preview-v0.7.0):

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_deb="chonkstep_0.7.0-1_amd64.deb"
curl -fL -o "$chonkstep_dir/$chonkstep_deb" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.0/$chonkstep_deb"
curl -fL -o "$chonkstep_dir/$chonkstep_deb.sha256" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.7.0/$chonkstep_deb.sha256"
(cd "$chonkstep_dir" && sha256sum --check "$chonkstep_deb.sha256")
sudo apt install "$chonkstep_dir/$chonkstep_deb"
```

Select **chonkstep** in LightDM for the next login. Verify package provenance
with:

```sh
gh attestation verify "$chonkstep_dir/$chonkstep_deb" \
  --repo iconidentify/chonkstep \
  --signer-workflow iconidentify/chonkstep/.github/workflows/lcos-package.yml
```
