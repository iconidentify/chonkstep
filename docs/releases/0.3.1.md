# ChonkStep 0.3.1 preview

ChonkStep 0.3.1 is a compatibility, stability and measured-efficiency release
for the native Wayland compositor and its Omarchy integration.

## Highlights

- Correct Microsoft Edge and Chromium text selection at 1x, 1.5x and 2x,
  windowed and fullscreen.
- Reliable key repeat across native Wayland and X11 applications, including
  focus changes, modal UI, input methods and live keymap/repeat updates.
- Resilient clipboard and primary selection across 19 real Wayland/X11
  transfer and lifecycle cases, including binary payloads, INCR, backpressure,
  cancellation, owner death and XWayland restart.
- Correct pointer lock/confinement and client-authorized move/resize behavior,
  with permanent Chonkcraft click/geometry coverage at three output scales.
- Stronger X11 lifecycle cleanup, Chromium configure ordering and Omarchy menu
  generation/startup handling.

## Measured work

- Stalled 8 MiB clipboard retention: **+8,196 KiB to 0 KiB anonymous PSS** in
  seven matched before/after trials, with every resumed payload byte verified.
- Hot 8 MiB partial-write helper: **8,192 temporary allocations requesting
  272,629,760 bytes cumulatively to zero**.
- Matched two-hour lifecycle soaks: **61.2% less requested-live Rust growth**,
  **9,999,644 fewer peak live bytes**, and **56.4% less anonymous+swap growth**.
- Locked-pointer work: **128 render attempts to zero**; an 8,192-report burst
  preserved every delta with zero render attempts or submissions.
- Hidden-Dock fixture: idle CPU **0.233% to 0.0833% of one core**, context
  switches **45.92 to 12.10 per second**, and 18 fewer startup threads.
- Normal 56px clock rendering: **52 to 32 allocator requests** with exact pixel
  equivalence at every integer size from 8 through 128.

## How it was tested

The principal memory comparison used matched 7,202-second baseline and
candidate lifecycle soaks totaling 59,089 churn cycles. Supporting evidence
includes seven alternating 60-second startup/idle samples per executable, 14
byte-verified clipboard trials, a 306-second paired allocation profile, 10,240
abrupt-client selection objects, and a final release gate of 199 nested cases
plus three installed-Omarchy checks with no skipped clients. Real Microsoft
Edge, Chromium and isolated Chonkcraft were included.

Raw samples, screenshots, immutable executable hashes and known limitations are
preserved in the repository. These are controlled nested/software-rendered
results, not a matched Hyprland comparison, native DRM/KMS frame-time result,
game FPS claim or proof of universal hardware behavior.

## Install on Arch or Omarchy

Choose the native `x86_64` or `aarch64` package:

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_arch="$(uname -m)"
chonkstep_pkg="chonkstep-0.3.1-1-$chonkstep_arch.pkg.tar.zst"
curl -fL -o "$chonkstep_dir/$chonkstep_pkg" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.3.1/$chonkstep_pkg"
curl -fL -o "$chonkstep_dir/SHA256SUMS" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.3.1/SHA256SUMS"
(cd "$chonkstep_dir" && sha256sum --ignore-missing --check SHA256SUMS)
sudo pacman -U "$chonkstep_dir/$chonkstep_pkg"
omarchy install desktop-chonkstep
```

Every package and matching debug-symbol package is built on its native
architecture, covered by `SHA256SUMS`, and carries GitHub build provenance.
