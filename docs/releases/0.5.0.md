# ChonkStep 0.5.0

Mac interaction mode, independent display Spaces, and a more observable GPU
pipeline. Published through the existing `preview-v0.5.0` prerelease channel.

- **Mac keyboard mode:** application-aware Command shortcuts for Wayland and
  XWayland apps, terminal copy/paste, application switching, Hide, Show Desktop,
  fullscreen Spaces, and familiar screenshot/recording shortcuts.
- **A Space row for each display:** local navigation and Overview, simultaneous
  fullscreen windows, live desktop thumbnails with accurately placed windows,
  and window membership preserved across reconnects.
- **Capture and share:** screen, window and region screenshots, region recording,
  a keyboard-driven capture overlay, and repeatable product-demo tooling.
- **Rendering improvements:** per-surface output tracking, refresh-aware frame
  callbacks, GPU-fence-driven capture downloads, improved native frame pacing,
  and counters that explain composition and scanout decisions.
- **Reviewed toggle behavior:** repeated live profile changes, adoption of an
  already-owned clipboard, and input-method keyboard-grab lifetime/focus fixes.

## Enable Mac mode

At the top of `~/.config/chonkstep/config.toml`, set
`interaction_mode = "mac"`, then run `scripts/reload.sh` from the source checkout.
Set it to `"desktop"` and reload to turn it off. No compositor restart is needed
for this setting. Invalid configuration keeps the working profile.

Command-Shift-5 opens capture controls. Command-Shift-3 captures the desktop;
Command-Shift-4 selects a region. The [Mac mode guide](../mac-mode.md) lists the
implemented shortcuts, application exceptions and current parity gaps.
Existing terminal configuration must retain its native clipboard actions;
physical Control-C continues to interrupt terminal programs.

## Performance and limits

Overlay-plane scanout and broader primary-plane acceptance are independent
experiments and remain **off by default**. The regular primary/cursor scanout
paths remain available. Multi-GPU rendering is explicitly configured. These
features are not a claim of universal acceleration or complete macOS parity.
The hardware reports include NVIDIA, AMD and Apple results, including an M1
scanout regression; see [GPU pipeline controls](../gpu-pipeline.md) and the
[cross-GPU benchmark report](../benchmarks/cross-gpu-2026-09-10/README.md).

The release review and reproducible demo instructions are in
[the review report](../engineering/2026-09-10-release-review.md) and
[product demos](../product-demos.md).

## Installing on LCOS

Download the amd64 package and its checksum from the
[0.5.0 release](https://github.com/iconidentify/chonkstep/releases/tag/preview-v0.5.0):

```sh
chonkstep_dir="$(mktemp -d)"
chonkstep_deb="chonkstep_0.5.0-1_amd64.deb"
curl -fL -o "$chonkstep_dir/$chonkstep_deb" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.5.0/$chonkstep_deb"
curl -fL -o "$chonkstep_dir/$chonkstep_deb.sha256" \
  "https://github.com/iconidentify/chonkstep/releases/download/preview-v0.5.0/$chonkstep_deb.sha256"
(cd "$chonkstep_dir" && sha256sum --check "$chonkstep_deb.sha256")
sudo apt install "$chonkstep_dir/$chonkstep_deb"
```

Select **chonkstep** in LightDM for the next login. The package carries GitHub
build provenance; verify it with
`gh attestation verify "$chonkstep_dir/$chonkstep_deb" --repo iconidentify/chonkstep --signer-workflow iconidentify/chonkstep/.github/workflows/lcos-package.yml`.

For Omarchy or other Arch systems, use the native `x86_64` or `aarch64`
packages and matching debug symbols from the same release. See the
[Arch installation instructions](../../README.md#installing-on-omarchy-or-any-arch).

The LCOS package contains the X11 session. Mac mode and the live Spaces/capture
demos in this release require the Wayland compositor in the native Arch packages.
