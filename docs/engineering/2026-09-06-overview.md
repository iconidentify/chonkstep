# Native Overview rendering — 2026-09-06

Wayland Overview now presents existing client textures and sparse frame buffers
at proportional sizes over the wallpaper. Desktop thumbnails sit at the top;
the selected window gets a thin outline and a cached caption. The output-sized
shell surface handles input and owns **zero pixel bytes**. X11 keeps its raster
fallback.

Packing uses at most 32 linear passes when the entry set changes, with a common
scale capped at 0.8. Portrait windows stay portrait, relative sizes survive,
windows never enlarge, and captions have reserved bottom space. Hover changes
an index; it neither captures nor rasterizes window pixels. Native Overview
suspends the periodic preview readbacks until close. Closing releases captions
and native scene records; only small shell identities survive.

The source/destination transform does not configure the client. Real surface
commits continue to update the miniature. Minimized clients may use their
existing small cached preview if the surface has no pixels. A new application
mapping while Overview is open now reaches its refresh handler even when there
is no saved session placement to restore.

## Release measurements

Same machine, nested winit inside headless Weston/pixman, llvmpipe, scale 2,
1280x800 compositor output. Six static foot windows requested at
900x550, 320x650, 520x320, 700x430, 280x220, and 480x300; normal compositor size
limits apply. Each binary ran three isolated sessions, each with 12 open/select/
close cycles and four selection keys per cycle. Final measurements ran after
compilation and E2E completed, before then after; host load and page caches were
not controlled. Input timing is cumulative time inside input dispatch, not
physical input-to-photon latency. PSS growth compares the same process just
before opening and at its first open Overview.

| Measurement | Before | After |
| --- | ---: | ---: |
| Median extra PSS while open | 19,888 KiB | 2,104 KiB |
| Median input-dispatch time per 12 cycles | 534,523 µs | 33,873 µs |
| Median shell time per 12 cycles | 148,384 µs | 5,635 µs |
| Median open-to-test-barrier round trip | 63.506 ms | 60.738 ms |
| Median selection-to-barrier round trip | 33.195 ms | 32.359 ms |
| p95 open-to-barrier round trip | 172.468 ms | 176.203 ms |

This supports about 89% less incremental memory and 94% less input-handler
work for this fixture. End-to-end timing did **not** improve proportionally;
the nested software presentation path dominates the measured frame wall time.
These results do not establish a hardware latency guarantee.
